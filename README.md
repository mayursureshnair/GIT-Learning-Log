## Branching and Working in Parallel

### Creating and switching branches

In this step, I'm creating a new branch and switch to it so that I can make a commit on the new branch. This will help me understand what will happen if I make a conflicting commit on main that I'll have to handle.

![Image](https://nextwork.ai/passionate_cyan_elegant_tuke/uploads/8bf3bcb5-a70d-418a-9c76-251365f69028_drz4zcda)

### Why merge conflicts occur

A merge conflict happens because the same file has been changed in 2 different branches and when it comes time to merge both files and changes together, there will be a conflict.
